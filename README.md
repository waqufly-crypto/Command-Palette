# Command Palette

Портативная всплывающая командная строка для Windows 10/11 — палитра
команд в духе PowerToys Run / Alfred: запуск программ, открытие путей и
URL, калькулятор, консольные команды, вставка даты/времени, системные
действия, история буфера обмена, преобразование выделенного текста и
управление настройками прямо из списка.

Версия: 1.9.1

- Один файл `main.py`, без внешних ресурсов: иконки рисуются QPainter,
  стили встроены в код
- Портативный режим: все данные — в подпапке `data` рядом с программой
- Глобальный хоткей по умолчанию: Alt+Space
- Шесть тем оформления, прозрачность окна, закрепление поверх всех окон

## Возможности

- Нечёткий поиск по командам: название, синонимы, метки, описание, цель
- Ранжирование с учётом частоты и свежести запусков
- Калькулятор прямо в строке ввода (безопасный разбор через AST)
- Открытие файлов, папок, программ (с аргументами) и URL
- Поиск в Google по префиксу `g`
- Консольные команды по префиксу `>`: скрыто с выводом в буфер или в окне cmd
- Команды даты/времени с вставкой в активное окно (форматы — в `commands.json`)
- Операции над выделенным текстом во внешнем окне: регистр и транслитерация
- Системные действия: блокировка, сон, выключение, корзина и др.
- История буфера обмена с быстрой вставкой (Ctrl+Alt+V), закреплением и метками
- Команды управления настройками: темы, сортировка, прозрачность, переключатели
- Метки команд, поиск по ним и пакетное выполнение отмеченных пунктов
- Сортировка списка: релевантность / название / последний вызов / ручная
- Недавние команды (Ctrl+R), история ввода (Ctrl+H), все команды (Ctrl+L)
- Глобальные хоткеи на отдельные команды — мгновенное исполнение без палитры
- Панель быстрых фраз, перетаскивание и изменение размера окна мышью
- Автозапуск через реестр, единственный экземпляр
- Показ на мониторе активного окна (мультимониторные конфигурации)

## Требования

- Windows 10/11 (приложение использует Win32 API)
- Python 3.10+ и PySide6

## Установка и запуск

```
pip install PySide6
pythonw main.py
```

`pythonw` запускает без окна консоли; `python main.py` удобен для
отладки. При первом старте рядом с программой создаётся папка `data`
с настройками и командами по умолчанию.

### Сборка exe (необязательно)

```
pip install pyinstaller
pyinstaller --noconfirm --onefile --windowed --name CommandPalette main.py
```

Папка `data` создаётся рядом с exe — программу можно носить на флешке.
Не размещайте её в `Program Files`: без прав записи настройки и история
не сохраняются (программа предупредит и продолжит работу).

## Горячие клавиши

Глобальные (работают из любого приложения):

| Комбинация | Действие |
| --- | --- |
| Alt+Space | Показать/скрыть палитру (настраивается: `hotkey`) |
| Ctrl+Alt+V | История буфера обмена (`clipboard_hotkey`) |
| Хоткей команды | Мгновенно выполнить команду без открытия палитры (поле `hotkey`) |

В окне палитры:

| Клавиша | Действие |
| --- | --- |
| Enter | Выполнить выбранный пункт (или все отмеченные) |
| Ctrl+Enter / Shift+Enter | Выполнить, не закрывая окно |
| Tab / Shift+Tab | Дополнить ввод названием пункта |
| Esc | Скрыть окно (ввод и меню запоминаются) |
| ↑ / ↓ | Выбор пункта; при пустом поле — листание истории ввода |
| PgUp / PgDn | Перемещение на страницу |
| Пробел (при пустом поле), Shift+Space, Ctrl+Space, Ctrl+M | Отметить пункт |
| Ctrl+Shift+A | Отметить все доступные / снять все |
| Ctrl+U | Снять все отметки |
| Ctrl+1 … Ctrl+4 | Сортировка: релевантность / название / последний вызов / ручная |
| Ctrl+↑ / Ctrl+↓ | Ручное перемещение пункта (включает режим «manual») |
| Ctrl+P | Закрепить/открепить окно |
| Ctrl+R | Недавние команды |
| Ctrl+H | История ввода |
| Ctrl+L | Все команды |
| Ctrl+Backspace | Удалить слово слева от курсора |

Мышь: клик по пункту выполняет его, Ctrl+клик — не закрывая окно,
Shift+клик — отмечает. Перетаскивание — за пустую область окна или
списка; изменение размера — за правый, нижний край и нижний правый угол
(ширина и число строк сохраняются в `config.json`).

Вставка даты/времени и буфера требует фокуса внешнего окна, поэтому
палитра скрывается даже при Ctrl+Enter — кроме случая, когда окно
закреплено.

## Поиск и режимы

| Ввод | Что происходит |
| --- | --- |
| обычный текст | Нечёткий поиск по командам (подстрока или акроним) |
| пусто | Все команды (если включён `show_all_on_empty`) |
| `*` / `*запрос` | Все команды / фильтр по всему списку |
| `= 2*(3+4)` | Калькулятор, явный режим |
| `2+2` | Калькулятор распознаётся и без «=» |
| `g запрос` | Поиск в Google в браузере по умолчанию |
| `> ipconfig /all` | Консольная команда (два варианта запуска) |
| `C:\Tools\app.exe -flag` | Открыть путь с аргументами |
| `notepad` | Голые имена ищутся в PATH и каталогах Windows |
| `example.com` | Открыть URL (https подставляется автоматически) |
| `#метка` | Все команды с меткой (совпадение по префиксу) |
| `#метка запрос` | Поиск внутри метки |
| `#` | Список всех меток |
| `#буфер` / `#буфер текст` | История буфера обмена, поиск по тексту и меткам |
| `#+метка, метка2` | Назначить метки отмеченным записям |
| `#-метка` | Снять перечисленные метки |
| `#!` / `#pin` / `#unpin` | Постоянное хранение записей буфера |

Если ничего не найдено, предлагается поискать запрос в сети.

### Консольные команды

Ввод, начинающийся с `>`, даёт два пункта:

- «Выполнить: …» — `cmd.exe /c` скрыто; вывод (и ошибки) попадает
  в буфер обмена, таймаут 120 секунд
- «В окне консоли: …» — `cmd.exe /k`, окно остаётся открытым

## Калькулятор

- Операторы: `+ - * / // % ^` (`^` — степень), скобки, унарный минус
- Запятая трактуется как десятичная точка: `2,5*4`
- Константы: `pi`, `e`, `tau`
- Функции: `sqrt sin cos tan asin acos atan log log2 log10 exp abs round
  min max floor ceil degrees radians pow factorial`
- Ограничения безопасности: длина выражения до 200 символов, до 120
  узлов разбора, степень до 512, факториал 0..1000
- Enter копирует результат в буфер обмена

## Дата/время

Команды даты/времени живут в `data/commands.json` (при первом запуске
версии 1.7 стандартный набор переносится туда автоматически; дальше
вы управляете ими сами). Все имеют метки `#дата` и `#время`.

- Форматы: ДД.ММ.ГГГГ, ISO, US, словами, с днём недели, время (ЧЧ:ММ
  и с секундами), дата и время (обычные, ISO, UTC, SQL), метка для имени
  файла, Unix timestamp (с и мс)
- В списке показывается превью; при исполнении значение вычисляется
  заново — всегда актуальное
- Enter копирует значение в буфер и вставляет его (Ctrl+V) в окно,
  которое было активным до открытия палитры
- Режим «только буфер обмена» переключается в трее, командой
  «Настройка: дата/время — вставка в окно» или ключом `datetime_insert`
- Свои форматы: команда с `"type": "datetime"`, `target` — strftime-формат
  (например `%d.%m.%Y %H:%M`) или спец-имя: `unix`, `unix_ms`, `utc_iso`,
  `ru_date`, `ru_weekday`, `ru_datetime`
- Поддерживаются спецификаторы `%a %A %b %B %c %d %H %I %j %m %M %p %S
  %U %w %W %x %X %y %Y %z %Z` и `%%`; прочие (например `%#d`)
  отклоняются с ошибкой

Пример команды с глобальным хоткеем:

```json
{
  "id": "dt:%Y-%m-%d %H:%M:%S",
  "name": "Дата и время SQL",
  "type": "datetime",
  "target": "%Y-%m-%d %H:%M:%S",
  "hotkey": "Ctrl+Alt+D",
  "tags": ["дата", "время"],
  "description": "ГГГГ-ММ-ДД ЧЧ:ММ:СС"
}
```

Зажатые модификаторы хоткея больше не мешают вставке: перед
синтетическим Ctrl+V программа отпускает Alt/Ctrl/Shift/Win (1.9.1).
Можно нажать Ctrl+Alt+D и не отпускать клавиши — дата вставится.

## Текст: регистр и транслитерация

Встроенные команды преобразуют выделенный текст **во внешнем окне**.
Все имеют метку `#текст` (плюс `#регистр` или `#транслит`).

| Команда | target | Пример |
| --- | --- | --- |
| ВЕРХНИЙ РЕГИСТР | upper | привет → ПРИВЕТ |
| нижний регистр | lower | ПРИВЕТ → привет |
| Каждое Слово С Заглавной | title | привет мир → Привет Мир |
| Как в предложении | capitalize | привет Мир → Привет мир |
| Инвертировать регистр | invert | Привет → пРИВЕТ |
| Кириллица → латиница | translit | Щукин → Shchukin |
| Латиница → кириллица | untranslit | Privet → Привет (приблизительно) |

Как это работает:

1. Выделите текст в любом приложении и вызовите команду — из палитры
   (Alt+Space) или по хоткею команды (палитра не открывается).
2. Программа возвращает фокус исходному окну, копирует выделение
   (Ctrl+C), преобразует его и вставляет обратно (Ctrl+V).
3. Результат остаётся в буфере обмена и попадает в историю буфера
   (если не длиннее 10 000 символов).

Строка ввода палитры не преобразуется — операция всегда применяется
к выделению внешнего окна.

Своя команда с хоткеем:

```json
{
  "name": "Транслит выделения",
  "type": "text",
  "target": "translit",
  "hotkey": "Ctrl+Alt+T",
  "tags": ["текст", "транслит"],
  "description": "Кириллица → латиница"
}
```

Транслитерация:

- Схема близка к BGN/PCGN: ё→yo, ж→zh, х→kh, ц→ts, ч→ch, ш→sh, щ→shch,
  ю→yu, я→ya; ъ и ь опускаются; регистр сохраняется
  (Щукин → Shchukin, ЩУКИН → SHCHUKIN)
- Поддержаны украинские і, ї, є, ґ
- Обратный транслит приблизительный: исходные ъ/ь/й/ы не восстановимы;
  c→к, h→х, x→кс, w→в, апостроф→ь

Ограничения и поведение:

- Длина выделения — до 200 000 символов
- Паузы между шагами задаются ключом `datetime_paste_delay_ms`
- Перед копированием прежний текст буфера запоминается и возвращается
  при неудаче; при успехе в буфере остаётся результат
- Во время операции захват истории буфера приостанавливается
- Повторный вызов во время выполнения отклоняется с предупреждением
- В терминалах копирование часто на Ctrl+Shift+C: Ctrl+C может не
  сработать — программа сообщит «Выделенный текст не получен» и вернёт
  прежний буфер

## Системные действия

| Действие | target | Подтверждение |
| --- | --- | --- |
| Блокировка экрана | lock | нет |
| Сон | sleep | нет |
| Выключение | shutdown | да |
| Перезагрузка | restart | да |
| Открыть Корзину | recycle | нет |
| Очистить Корзину | empty_recycle | нет — удаляет сразу! |
| Перезапустить Проводник | restart_explorer | нет |

Все системные команды имеют метку `#система`.

Примечание: при включённой гибернации Windows команда «Сон» уходит в
гибернацию. Отключить: `powercfg /h off` (от администратора).

## Метки и пакетное выполнение

- Поле `tags` в `commands.json` — список или строка:
  `"tags": ["работа", "текст"]` или `"tags": "работа, текст"`
- Обычный поиск находит команды и по меткам (приоритет: название →
  синонимы → метки → описание → цель)
- `#работа` — все команды метки, `#работа блок` — поиск внутри метки,
  `#` — список всех меток
- `#+работа, личное` — назначить метки, `#-работа` — снять. Цель:
  отмеченные строки, иначе текущая (последняя выделенная)
- Метки пользовательских команд хранятся в `state.json`
  (`tag_overrides`), метки записей буфера — вместе с записями
- Встроенные метки: `#система`, `#дата`, `#время`, `#текст`, `#регистр`,
  `#транслит`, `#настройки`

Отметки и пакетный запуск:

- Отметить: Пробел при пустом поле, Shift+Space, Ctrl+Space, Ctrl+M
  или Shift+клик; Ctrl+Shift+A — все, Ctrl+U — снять
- Отмеченные строки подсвечиваются полосой и значком ✓, внизу окна
  показывается счётчик
- Enter выполняет все отмеченные команды последовательно; опасные
  действия спрашивают подтверждение один раз, выключение и
  перезагрузка всегда выполняются последними

## История буфера обмена

- Ctrl+Alt+V (или `#буфер`) — список истории; Enter вставляет выбранный
  текст в исходное окно и поднимает его наверх списка
- Захватывается только текст до 10 000 символов; глубина —
  `clipboard_limit` (по умолчанию 30); отключение —
  `"clipboard_history": false`
- `#!` (или `#pin` / `#unpin`) — постоянное хранение записи: она не
  вытесняется новыми и переживает очистку истории; помечается 📌
- `#+метка` на отмеченных записях буфера назначает метки; по ним
  работает поиск `#метка` и фильтр внутри `#буфер`
- Результаты операций над текстом тоже попадают в историю
- Успешная вставка не показывает уведомление трея (только лог)

Внимание: история буфера хранится в `state.json` в открытом виде.
Не копируйте пароли при включённой истории или отключите её.

## Настройки прямо из палитры

Команды с меткой `#настройки` меняют поведение программы без открытия
файлов; в подзаголовке показывается текущее состояние («Сейчас: вкл»,
«Сейчас: dark», «Сейчас: 90%»).

- Переключатели: дата/время — вставка в окно; история буфера обмена;
  окно под курсором; все команды при пустом вводе; панель быстрых фраз;
  закрепить окно (поверх всех)
- «Сортировка: по релевантности / по названию / по последнему вызову /
  ручная»
- «Тема: Тёмная / Светлая / Полночь / Лес / Solarized Dark / Dracula»
- «Прозрачность: 100% … 30%»
- «Настройка: перезагрузить команды и конфиг», «…автозапуск Windows»,
  «…очистить историю ввода», «…очистить буфер (кроме закреплённых)»

После выполнения такой команды список перестраивается, но выделение
и прокрутка остаются на том же пункте (1.9.1) — настройку удобно
переключать несколько раз подряд.

## Сортировка списка

| Режим | Клавиша | Порядок |
| --- | --- | --- |
| score | Ctrl+1 | По релевантности и статистике запусков |
| name | Ctrl+2 | По названию |
| last | Ctrl+3 | По времени последнего вызова |
| manual | Ctrl+4 | Ручной порядок (Ctrl+↑ / Ctrl+↓) |

Режим сохраняется в `config.json` (`sort_mode`), ручной порядок —
в `state.json` (`sort_order`). Смена режима и перемещение пунктов
сохраняют текущее выделение.

## Оформление и поведение окна

- Темы: `dark`, `light`, `midnight`, `forest`, `solarized`, `dracula` —
  из меню трея или командами «Тема: …». Свои цвета в `config.json`
  соответствуют режиму `custom`
- Прозрачность окна: 30–100% (меню трея или команды «Прозрачность: …»)
- Закрепление (Ctrl+P, трей или команда): окно не скрывается при потере
  фокуса и клике мимо, а также не скрывается при выполнении команд
- Панель быстрых фраз: кнопки под полем ввода вставляют заготовку
  (`phrases_enabled`, `phrases`); по умолчанию `g `, `> `, `#буфер`,
  `= `, `https://`, `*`
- Окно без рамки, поверх всех; показывается на мониторе активного окна
  или под курсором мыши (`window_under_cursor`)
- Повторный вызов восстанавливает последний запрос вместе с меню:
  результатами, выделенной строкой и прокруткой (включая режимы
  Ctrl+R / Ctrl+H / буфера). Превью даты/времени может немного устареть —
  при исполнении значение вычисляется заново
- Всплывающие уведомления трея отключены: события пишутся в
  `data/app.log`; критические ошибки запуска показываются диалогом

## Пользовательские команды (data/commands.json)

```json
{
  "commands": [
    {
      "name": "Блокнот",
      "type": "path",
      "target": "%WINDIR%\\system32\\notepad.exe",
      "synonyms": ["notepad", "текст", "редактор"],
      "tags": ["работа", "текст"],
      "hotkey": "Ctrl+Alt+N",
      "description": "Открыть Блокнот",
      "icon": "app"
    },
    {
      "name": "Дата для отчёта",
      "type": "datetime",
      "target": "%d.%m.%Y",
      "tags": ["работа", "дата"],
      "description": "ДД.ММ.ГГГГ"
    }
  ]
}
```

Поля записи:

| Поле | Обяз. | Описание |
| --- | --- | --- |
| name | да | Название в списке |
| type | нет | `path` (по умолчанию), `url`, `datetime`, `system`, `text` |
| target | да | Путь / URL / формат даты / системное действие / операция над текстом (`upper`, `lower`, `title`, `capitalize`, `invert`, `translit`, `untranslit`) |
| args | нет | Аргументы запуска (для `path`) |
| synonyms | нет | Список альтернативных названий для поиска |
| tags | нет | Метки: список или строка через запятую |
| hotkey | нет | Глобальный хоткей команды, например `Ctrl+Alt+N` |
| description | нет | Подзаголовок в списке |
| icon | нет | Ключ иконки или символ/эмодзи (1–2 знака) |
| id | нет | Стабильный ключ статистики (иначе вычисляется из записи) |

В `target` подставляются `{app}` (папка программы), `{data}` (папка
данных), переменные окружения `%VAR%` и `~`.

Ключи иконок: `app folder file url search calc lock sleep power restart
trash terminal settings info error clock history clipboard console`.
Без `icon` иконка подбирается по типу и расширению цели.

После правок выполните «Перезагрузить команды» в меню трея (или команду
«Настройка: перезагрузить команды и конфиг») — перезапуск не нужен.

## Хоткеи команд

- `"hotkey": "Ctrl+Alt+N"` — команда исполняется сразу, без открытия
  палитры; опасные системные действия спрашивают подтверждение
- Команды `datetime`, `text` и вставка из буфера работают с окном,
  активным в момент нажатия хоткея
- Перед синтетическим Ctrl+V/Ctrl+C зажатые Alt/Ctrl/Shift/Win
  отпускаются, поэтому комбинация хоткея не «портит» вставку (1.9.1)
- Проверяются корректность и конфликты (с хоткеями палитры/буфера и
  между командами); проблемные пропускаются с предупреждением в лог
- Лимит — 32 хоткея; перерегистрация — при «Перезагрузить команды»

Формат: модификаторы `Ctrl`, `Alt`, `Shift`, `Win` (или `Meta`/`Super`)
+ клавиша: буквы, цифры, `F1`–`F24`, знаки препинания и именованные
(`Space`, `Enter`, `Tab`, `Esc`, `Backspace`, `Insert`, `Delete`, `Home`,
`End`, `PageUp`, `PageDown`, стрелки, `PrintScreen`, `Pause`, `Plus`,
`Minus`…). Модификатор обязателен, кроме `F13`–`F24`. Пустая строка
отключает хоткей. Примеры: `Alt+Space`, `Ctrl+Shift+P`, `F13`.

## Хранение данных

Всё лежит в `data` рядом с exe или `main.py`:

| Файл | Содержимое |
| --- | --- |
| config.json | Настройки интерфейса и поведения |
| commands.json | Пользовательские команды (включая дату/время) |
| state.json | История ввода, статистика запусков, история буфера, ручной порядок, метки |
| app.log (+ .1–.3) | Лог с ротацией ~1 МБ × 3 |

- Запись атомарная (временный файл + замена) — файлы не портятся при
  сбое питания; состояние сохраняется с задержкой 2 с
- Повреждённый JSON переименовывается в `.bak`, загружаются значения
  по умолчанию (с предупреждением)
- Данные старых версий из корня программы автоматически переносятся
  в `data`
- Статистика запусков ограничивается 500 самыми полезными записями
- Повторный запуск невозможен: второй экземпляр сообщает об уже
  работающей программе (иконка в трее)

## Устранение неполадок

| Симптом | Решение |
| --- | --- |
| Хоткей не работает, в логе «занят» | Комбинацию перехватывает другое приложение — измените `hotkey` в `config.json` и перезагрузите команды |
| Хоткей команды нажимается, но значение не вставляется | В версиях до 1.9.1 зажатые Ctrl/Alt превращали Ctrl+V в Ctrl+Alt+V — обновитесь; проверьте `datetime_insert` и что целевое окно принимает Ctrl+V |
| Выделение «уезжает» на первый пункт после команды настройки | Исправлено в 1.9.1 — обновитесь |
| «Путь не найден» | Проверьте `target`; голые имена ищутся в PATH и каталогах Windows, полный путь должен существовать |
| «Сон» уходит в гибернацию | `powercfg /h off` от администратора |
| Настройки/история не сохраняются | Папка программы без прав записи (например, Program Files) — переместите её |
| Вставка даты/буфера не срабатывает | Целевое окно сменилось или не принимает Ctrl+V — значение остаётся в буфере; увеличьте `datetime_paste_delay_ms` |
| «Выделенный текст не получен» | Текст не был выделен, окно сменилось или копирует по Ctrl+Shift+C (терминалы) — выделите текст и повторите; прежний буфер восстановлен |
| Окно не скрывается при клике мимо | Включено закрепление — Ctrl+P или пункт трея «Закрепить окно» |
| Нет всплывающих уведомлений | Они отключены намеренно: смотрите `data/app.log` |
| Программа «не запускается» | Она уже работает в трее — нажмите Alt+Space |
